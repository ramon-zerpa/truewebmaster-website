## Motion for the future Astro build

- On desktop pointer hover, move the screenshot upward within its clipped viewport, inspired by the project previews on the legacy True Webmaster homepage. Restore its start position when the pointer leaves. Tune duration to the excerpt length so the content remains inspectable.
- Keep the project link separate from the hover target, so visitors can open the case or site without interrupting the preview.
- For keyboard focus, provide a usable preview or equivalent control; do not make the evidence available only on hover.
- On touch screens, show a useful static crop and a clear link. Respect reduced-motion preferences.
- Produce optimized, appropriately sized preview assets for the public site. The full-resolution PNGs here are Pencil source material, not production-ready assets.
